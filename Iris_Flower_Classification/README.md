# Iris Flower Classification

## Task
This project is developed as part of the CodeAlpha Machine Learning Internship.

## Objective
The objective of this project is to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

using machine learning.

## Dataset
The Iris dataset contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target:
- Species

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Machine Learning Algorithm
Decision Tree Classifier

## Steps
1. Load the dataset
2. Remove unnecessary columns
3. Split the data into training and testing sets
4. Train the Decision Tree model
5. Predict flower species
6. Evaluate model accuracy

## Output
The trained model predicts the species of Iris flowers and displays the model accuracy.
