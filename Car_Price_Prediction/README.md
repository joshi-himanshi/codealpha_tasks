# Car Price Prediction using Machine Learning

## Project Overview

This project predicts the selling price of a car using Machine Learning. A Linear Regression model is trained on historical car data to estimate the selling price based on different car features.

## Objective

The objective of this project is to build a regression model that predicts the selling price of a car using various input features.

## Dataset

The dataset contains information such as:

- Car Name
- Year
- Selling Price
- Present Price
- Driven Kilometers
- Fuel Type
- Selling Type
- Transmission
- Owner

Target Variable:
- Selling_Price

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Algorithm

- Linear Regression

## Project Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset
4. Check Missing Values
5. Convert Categorical Data using LabelEncoder
6. Split Features and Target
7. Split Training and Testing Data
8. Train Linear Regression Model
9. Predict Selling Price
10. Evaluate Model using R² Score

## Result

- Algorithm: Linear Regression
- Model Score (R²): **0.84**

The model successfully predicts car selling prices with good performance.
